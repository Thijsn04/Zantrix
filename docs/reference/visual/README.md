# Approved visual reference — 16 October 2026

The owner explicitly approved the current Teal patient-workspace study as Zantrix's visual and ergonomic reference. See [the authoritative design specification](../../visual-direction.md#approved-reference-baseline) and R155–R156 in the [decision register](../../decisions.md).

- [Approved standalone design snapshot](2026-10-16-approved-teal-reference.html)
- [Approval and integrity receipt](2026-10-16-approval.json)

The snapshot preserves the approved composition and synthetic interactions: the sole shell patient header, birth-date/close tabs, persistent dirty markers, stable filled/empty desktop columns, compact tables/forms, neutral non-alert status, Dutch decimal commas and retained value/unit alignment. Its baseline colors are brand #0F766E, selection #ECF8F5 and canvas #F4F6F8. Inter 4.1 uses the verified cv05/cv08/zero features and tabular figures. The receipt identifies the source and exported snapshot by SHA-256 and records the verified font-file identity.

This is documentation/reference material, not the Zantrix application, an SDK implementation, clinical validation, accessibility certification or a deployed website. All patients, values and preparations are fictitious. No backend, real record, prescribing or clinical finalization is connected. Demo drafts remain volatile and may disappear on refresh or process loss. The browser export wrapper is for inspecting the reference and does not define the production runtime.

The snapshot loads the version-pinned Inter font from an external static CDN. It is not an offline font bundle and does not select production asset hosting, font packaging or fallback policy. Font loading and clinical module/runtime delivery remain separate concerns. If the font is unavailable, the snapshot reports that its fallback glyph comparison is unreliable.

Visual review and local prototype behavior checks are recorded in the design document. They do not prove the real inline host, a future SDK, clinical access control or server-side draft durability. An asynchronous visibility check in this study is presentation behavior, not an authorization boundary.

Keep this approved dated snapshot unchanged. Intentional later revisions should have a new identifiable baseline and review, preserving this reference and its receipt.
